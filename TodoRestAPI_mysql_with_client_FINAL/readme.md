# Todo APP -  Backend + Frontend


1. venv + activate im Projekt
```
   python -m venv .venv   
   .venv\Scripts\Activate  
```
2. requirement.txt erstellen (aus alten Projekt)
    pip freeze  > requirements.txt   
3. pip install -r requirements.txt   
4. XAMPP installieren / starten (bei mysql)
5. DB erstellen
6. start.bat evtl. anpassen und starten
